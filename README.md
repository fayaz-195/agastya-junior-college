# Agastya Junior College — Static Website

A responsive multi-page website concept for Agastya Junior College.

## Pages
Home, About, Programs, Campus, Admissions, Contact.

## Brand
Teal #04959F and orange #E6760D. The official logo and campus photographs are referenced from the existing Agastya website.

## Before launch
- Verify all copy, contact information and campus claims with the college.
- Connect the enquiry form to the approved CRM/WhatsApp endpoint.
- Test image availability and mobile/desktop layouts.
- This is a new static rebuild, not a complete one-to-one WordPress export.
